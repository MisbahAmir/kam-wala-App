# 🚰 Plumbing Service App 

> ⚡ A real-time on-demand plumbing service application built using Flutter and Firebase, connecting customers with nearby plumbers like an Uber-style service platform.

---

## 📌 Description
Plumbing Service App is a Flutter-based mobile application that allows users to book plumbing services instantly or schedule them later. The app uses Firebase as the backend for authentication, real-time database, and notifications, providing a smooth and scalable service experience.

---

## 🚀 Features

### 👤 Customer Features
- 📍 Find nearby plumbers using GPS
- 🧰 Book plumbing services instantly or schedule later
- 🗺️ Real-time service tracking
- 💬 Chat with plumber (if implemented)
- ⭐ Rate and review services

### 👨‍🔧 Plumber Features
- 📩 Accept or reject service requests
- 🚗 Navigate to customer location
- 🔄 Update job status (On the way / Completed)
- 📊 View job history

### 🧑‍💼 Admin (Optional)
- 👥 Manage users and plumbers
- 📊 Monitor bookings
- ✔ Approve plumber accounts

---

## 🛠️ Technologies Used
- Flutter (Dart)
- Firebase Authentication
- Firebase Firestore (Database)
- Firebase Cloud Messaging (Notifications)
- Google Maps API

---


## ⭐ Project Purpose
This project demonstrates a real-world service marketplace system where users can book plumbing services on demand with real-time tracking and Firebase-powered backend services.
